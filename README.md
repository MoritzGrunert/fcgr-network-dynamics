# fcgr-network-dynamics
Analysis of weight dynamics and feature emergence in fully connected neural networks trained on FCGR-encoded sequences.

```bash
conda env create -f environment.yml
```

```bash
conda activate fcgr-analysis
```

add

```bash
conda env update -f environment.yml --prune
```

reset

```bash 
conda remove -n fcgr-analysis --all
conda env create -f environment.yml
```
